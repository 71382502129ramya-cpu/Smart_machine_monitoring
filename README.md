# Industrial Machine Monitoring — Software Demo

This is a single-page, software-only dashboard for demonstrating an ESP32 machine-monitoring project.

## Important
- All readings are generated by JavaScript in the browser.
- It is NOT connected to an ESP32, physical sensors, a machine, or a cloud database.
- LED, buzzer, and relay indicators are simulated UI states only.
- The dashboard is a demonstration prototype, not a certified industrial safety system.

## Run locally
Open `index.html` in a modern browser.

## Deploy to a public link using GitHub + Vercel
1. Sign in to GitHub and create a new repository, e.g. `industrial-machine-monitor-demo`.
2. Upload `index.html` to the repository root (top level). You can also upload this README.
3. Open https://vercel.com/ and sign in with GitHub.
4. Select **Add New → Project**, then import your `industrial-machine-monitor-demo` repository.
5. For a plain HTML project, choose **Other** as the framework preset if prompted. Leave Build Command and Output Directory empty if Vercel allows it; there is no build step.
6. Click **Deploy**.
7. After deployment, Vercel provides a URL like `https://your-project-name.vercel.app`. Open it and test all three scenario buttons.
8. Share that URL with your faculty. Keep the simulation notice visible when presenting.

## Demo script
1. Open the public link and explain that this is a software simulation.
2. Click **Simulate Normal**: green status, buzzer off.
3. Click **Simulate Warning**: yellow status, warning message.
4. Click **Simulate Critical**: red status, buzzer indicator on and simulated relay trip.
5. Explain that actual sensor data requires a separate ESP32 Wi-Fi integration.
